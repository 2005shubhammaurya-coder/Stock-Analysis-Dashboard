# Stock Analysis Dashboard

An interactive Power BI dashboard that analyses DMart (Avenue Supermarts Ltd) stock data from 25 Sep 2025 to 25 Sep 2026.

## Features
- Summary cards for High, Low, Open, Close and Total Volume
- Trades per day and monthly trade trend charts
- Monthly trading volume comparison
- Daily high price trend with Quarter > Month > Day drill-down
- Dropdown filters for Day, Month and Quarter

## Tools Used
Power BI Desktop

## How to Open
Download `Stock_Analysis_Dashboard.pbix` and open it in Power BI Desktop.
